# Student Performance Tracker - Version 2

## About My Project

A simple Python project to manage student details and track their academic performance.

Version 2 improves the project by adding input validation, exception handling, better search, performance analysis, and improved JSON data handling.

## Features

- Add Student
- View All Students
- Search Student by Roll Number
- Search Student by Name
- Update Student
- Delete Student
- Student Performance Report
- Calculate Total, Average and Percentage
- Find Highest and Lowest Subject Marks
- Grade and Pass/Fail Result
- Top 3 Performers
- Class Statistics
- Input Validation
- Exception Handling
- Save Data to JSON
- Load Data from JSON
- Clear All Data
